# ת״ש חובה בח״א צריפין

אתר מובייל-ראשון (עברית, RTL) שמרכז זכויות, מדריכים ואנשי קשר בת״ש לחיילי חובה בצריפין.
Astro סטטי, ללא Backend וללא איסוף מידע אישי.
בגרסה שב-Vercel פועל מונה צפיות אנונימי (Vercel Web Analytics): נתיב העמוד, סוג המכשיר והמדינה. בלי עוגיות, ובלי מילות החיפוש שמקלידים.

## מה יש באתר
- זכויות, מדריכים (כולל הפקת אישורים מהבנק), אנשי קשר, שאלות נפוצות ומילון מושגים.
- חיפוש כללי מדף הבית, וחיפוש חי בתוך כל רשימה.
- שאלון "מאיפה מתחילים" שמוביל לזכויות הרלוונטיות.
- הדרכה קצרה לכל עמוד (כפתור ?).

## הרצה
```bash
npm install
npm run dev      # פיתוח (מציג גם טיוטות)
npm run build    # בנייה לפרסום (רק תוכן approved)
```

## בדיקות
```bash
npm run verify          # הכול: טיפוסים, תוכן, בדיקות יחידה, בנייה ובדיקות דפדפן ב-320/375/390px
npm run check:content   # פערי תוכן (אזהרות) והפניות שבורות (שגיאות)
npm run test:unit       # מנוע החיפוש, נירמול הטקסט וסקריפט האישור
```
בפעם הראשונה צריך להוריד את דפדפן הבדיקות: `npx playwright install chromium`.
Vercel בונה עם `npm run build:checked`, כך שבדיקה שנכשלת משאירה את הגרסה הקודמת באוויר.

## עיקרון מרכזי
**תוכן מקצועי לא מתפרסם בלי `status: approved`** (מקור, עמוד ומאשר מתועדים). בנייה לפרודקשן מסננת טיוטות אוטומטית.

## מבנה
```
src/content/     זכויות, בנקים, מדריכים
src/data/        אנשי קשר, מסגרות, קישורים, שאלות נפוצות, מילון, שאלון, מילים נרדפות לחיפוש
src/pages/       עמודי האתר
src/components/  רכיבים משותפים
src/lib/         חיפוש (search-core, page-search), הדרכה (tour), כלי עזר
src/styles/      טוקנים ועיצוב
tests/           בדיקות יחידה (unit) ובדיקות דפדפן (e2e)
scripts/         בדיקת תוכן, אישור תוכן, הכנת תמונות, ניקוי CSS
_source/ _work/  (מקומי בלבד, לא ב-git) הספר המקצועי וחומרי עבודה
```
