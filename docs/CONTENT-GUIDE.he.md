# מדריך למתחזק: איך מעדכנים את האתר

אין צורך לדעת תכנות. כל התוכן הוא קבצי טקסט. אחרי שמירה, האתר נבנה מחדש לבד. אם משהו חסר או שגוי, הבנייה נעצרת עם הודעה, והאתר הקיים נשאר שלם.

## איפה כל דבר נמצא

| מה | איפה |
|---|---|
| אנשי קשר (שם, טלפון, וואטסאפ) | `src/data/people.yaml` |
| איזו יחידה שייכת למי | `src/data/assignments.yaml` |
| מסגרות (אופק, לה״ב...) | `src/data/frameworks.yaml` |
| בנקים והדרכות | `src/content/banks/` (קובץ לכל בנק) |
| זכויות | `src/content/rights/` (קובץ לכל זכות) |
| מדריכים כלליים | `src/content/guides/` |
| קישורים למערכות | `src/data/links.yaml` |

## לשנות מספר טלפון
1. פתחו `src/data/people.yaml`, מצאו את השם ושנו `phone` (10 ספרות, בלי מקפים, למשל `"0501234567"`).
2. שמרו. המספר מתעדכן בכל מקום באתר.

## להפעיל כפתור וואטסאפ
ב-`people.yaml` שנו `whatsapp: unknown` ל-`whatsapp: yes`, **רק אחרי שבדקתם שהמספר באמת בוואטסאפ**.

## להוסיף איש קשר או להעביר יחידה
1. הוסיפו אדם חדש ב-`people.yaml` (העתיקו בלוק קיים ושנו `id` ושאר השדות).
2. ב-`assignments.yaml` הוסיפו שורה עם המסגרת, היחידות והאדם.

## להוסיף זכות חדשה
1. העתיקו את `src/content/rights/_template.md` לקובץ חדש בשם באנגלית, למשל `rent-support.md`.
2. מלאו את השדות לפי ההערות בתבנית.
3. השאירו `status: draft`. **זכות לא תופיע באתר עד שתאושר.**

## איך מאשרים תוכן לפרסום
תוכן עולה לאתר רק עם `status: approved`. לאישור חייבים:
- `approvedBy` ו-`approvedOn`
- מקור ועמוד (`sources`) לתוכן מקצועי
- אין רשומות ב-`open_issues`
- סכומים: בשדה `figures` עם `asOf` (תאריך תוקף) ומקור

תוכן שהועתק מהאתר הדוגמה נשאר `draft` עד שיאומת מול הספר או אסמכתא רשמית.

## להוסיף בנק או מדריך בנק
1. העתיקו `src/content/banks/_template.yaml.txt` לקובץ חדש `<שם>.yaml`.
2. הקישור לפלייליסט מאושר בנפרד מהמדריך הכתוב: `status` לקישור, `guideStatus` לשלבים הכתובים.
3. מדריך כתוב מאושר דורש `guideVerified` (תאריך בדיקה מול האפליקציה).

## כללי YAML חשובים (מונעים רוב השגיאות)
- פריט ברשימה שיש בו נקודתיים (`:`) חייב להיות בתוך מרכאות: `- "מי פטור: זכאי תשמ״ש"`.
- מספר טלפון תמיד בין מרכאות.
- הזחה (רווחים בתחילת שורה) היא חלק מהמבנה. אל תשנו אותה.
- כתבו ראשי תיבות עם ״ (גרשיים עבריים), למשל מש״קית.

## בדיקה לפני פרסום
```bash
npm run build
```
אם יש שגיאה, ההודעה תגיד באיזה קובץ ובאיזה שדה. כדי לראות גם טיוטות בזמן עבודה: `npm run dev`.
